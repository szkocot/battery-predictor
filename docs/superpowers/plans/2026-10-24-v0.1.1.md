# Battery Predictor 0.1.1

Requested scope: show minutes below one hour; hide while actively charging; show hours and minutes in clicked menu; use 🪫 as logo.

Design: BatteryEstimate exposes compact title, detailed title and visibility. Floor time to complete minutes, preserve `-1h` for unavailable input, show `0m` below one minute. Only isCharging hides the item; external power with charging stopped remains visible. Keep the status item alive and update isVisible so power notifications restore it. Refresh estimate when opening the menu. Use the system-rendered 🪫 emoji for the app icon and menu heading.

Plan: write and run failing formatter/visibility tests; implement model and AppKit integration; render emoji into a complete macOS iconset, package its ICNS; bump VERSION to 0.1.1; run tests and universal build, inspect icon and bundle; review; publish v0.1.1 and verify release assets.
